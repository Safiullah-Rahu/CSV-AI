# Northwind Traders — IT Security Standard (sample)

> Sample content shipped with the platform. Northwind Traders is a fictional company.

## Passwords and MFA

Passwords must be at least 14 characters. Multi-factor authentication is mandatory for email, VPN and finance systems.

## Data classification

Data is classified as Public, Internal, Confidential or Restricted. Restricted data (salaries, health records)
may only be stored in approved systems and must never be shared with external AI tools.

## Incident reporting

Report suspected phishing or data loss to security@northwind.example within one hour.
